Third-party code included in the apitofsim native extension

The extension contains compiled code from the projects listed below,
including code instantiated from headers. Their license texts are in this
directory. These links identify the upstream source repositories and the
versions pinned by the bundled build configuration.

nanobind (BSD-3-Clause)
Source: https://github.com/wjakob/nanobind/tree/v2.9.2

robin-map (MIT), used by nanobind
Source: https://github.com/Tessil/robin-map/tree/v1.4.0

concurrentqueue (BSD-2-Clause or Boost-1.0)
Source: https://github.com/cameron314/concurrentqueue/tree/v1.0.4

LightweightSemaphore includes adaptations of Jeff Preshing's semaphore
implementation under the zlib license.
Original source: https://github.com/preshing/cpp11-on-multicore/blob/master/common/sema.h
Adapted source: https://github.com/cameron314/concurrentqueue/blob/v1.0.4/lightweightsemaphore.h

magic_enum (MIT)
Source: https://github.com/Neargye/magic_enum/tree/v0.9.7

Eigen (primarily MPL-2.0)
Source: https://gitlab.com/libeigen/eigen
Pinned source for builds using the Meson fallback:
https://gitlab.com/libeigen/eigen/-/tree/5.0.0
Builds using a separately supplied Eigen use the source corresponding to
that package's version. Eigen's source includes component-specific notices.
